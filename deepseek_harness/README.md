# DeepSeek Harness

Home Assistant add-on that runs the [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)
agent with Home Assistant, Supervisor, configuration and add-on-builder access.

See [DOCS.md](DOCS.md) for what it does and how to use it, and the repository
[README](https://github.com/ussdeveloper/ha-deepseek-harness) for architecture,
security model and development.
